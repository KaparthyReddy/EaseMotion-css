# CSS Travel Insurance Card (#70915)

Travel insurance summary card component featuring a responsive coverage limit grid, vector icons, active policy badge, and interactive hover mechanics in pure CSS.

## Features
- **Comprehensive Summary UI:** Clean travel booking aesthetic displaying policy status, pricing, and coverage limits.
- **Coverage Feature Grid:** Two-column grid layout highlighting individual coverage items (Medical, Delay, Cancellation, Baggage) with vector SVG indicators.
- **Pure CSS Micro-Interactions:** Smooth card elevation, border accent lighting, and subtle icon hover effects without JavaScript.
- **Accessible & Responsive:** Semantic `<article>` structure, screen reader `aria-label` declarations, mobile flex fallback, and full `@media (prefers-reduced-motion: reduce)` support.

## Structure
- `style.css` - Card styles, coverage grid layout, hover micro-interactions, and media query breakpoints.
- `demo.html` - Interactive demo displaying the travel insurance summary card.
