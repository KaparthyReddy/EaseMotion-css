# Crookes Radiometer Vane (#71072)

A Crookes radiometer light-driven rotating vane component housed within a glass bulb silhouette.

## Features
- Pure CSS continuous spin motion driven by light hotspot highlight styling.
- Dual-sided alternating silver and dark vane surfaces.
- BEM-based human-readable component classes (`ease-crookes-radiometer-vane`).
- Accessible with motion details marked `aria-hidden="true"`.
- Respects `prefers-reduced-motion` accessibility preferences.
