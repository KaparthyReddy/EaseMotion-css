# Michelson Interferometer Fringe (#71071)

A physics instrument visualizer modeling a Michelson interferometer's circular interference fringe drift across an optical detector plane.

## Features
- Phase-shifting concentric fringe effect rendered via CSS `repeating-radial-gradient`.
- Beam splitter optical glass reflection using composite `mix-blend-mode` overlays.
- Precision measurement crosshairs target overlay.
- Accessible (`aria-hidden="true"` decoration) with `prefers-reduced-motion` handling.
- Human-readable BEM CSS hierarchy (`ease-michelson-interferometer-fringe`).
